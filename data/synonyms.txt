# 전략물자관리 도메인 동의어 사전 (Stage 5)
#
# 형식: 한 줄 = 한 동의어 그룹, 쉼표로 구분, 전부 서로 동의어(양방향).
#       '#' 주석. 표제어를 kiwi 로 토큰화해 **토큰열 단위**로 매칭하므로
#       '자가 판정'처럼 띄어 쓴 표기를 따로 적을 필요는 없다(토큰이 같아진다).
#
# 원칙 — 발표에서 방어할 수 있어야 한다:
#   1. 민원인이 실제로 쓰는 말 ↔ 고시·시스템이 쓰는 말 을 잇는다.
#   2. 상위어-하위어는 넣지 않는다. '판정'↔'자가판정' 같은 건 노이즈만 만든다.
#   3. 평가셋 6건만 겨냥해 만들면 점수는 오르고 배우는 건 없다. 도메인 용어를 넓게 넣고
#      **노이즈까지 같이 측정**한다(현재 20개 그룹 중 평가셋과 관계있는 건 6개).
