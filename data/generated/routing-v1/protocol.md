# 44단계 라우터 실험 사전 설정

- 입력: 27단계의 고정된 135문항·세 검색 방식 결과. 현재 서버 결과로 해석하지 않는다.
- 비교: hybrid 고정, 질문 특징 라우터, 질문+검색 결과 특징 라우터, 오라클.
- 모델: 방식별 hybrid 대비 근거 Recall@5 차이를 예측하는 깊이 2 회귀 트리. 잎 최소 8문항. 예측 이득이 0.02를 초과할 때만 전환한다. 동률은 hybrid 유지. MRR은 보조 보고만 하고 학습에 사용하지 않는다.
- 특징: 질문 길이·단어 수·숫자·영문·조항·연도·인용·의문 표현; 결과 특징은 상위 5 부모/청크 수와 검색 방식 간 일치도. 정답·답안·질문 ID·문서 이름·유형 라벨은 모델 입력으로 금지한다. 저장된 결과에 점수가 없어 점수차 특징은 제외한다.
- 분할: 정답 부모가 하나라도 겹치는 질문들의 연결 성분을 묶고 5개 fold에 균등 배정한다. 각 fold는 나머지 fold로 학습한 모델로만 예측한다. seed=44. 동일 문서의 유사 질문이 학습·평가에 섞이지 않게 한다.
- 불확실성: 문서 묶음 단위 paired bootstrap 5,000회, seed=44. 참고용이며 이미 분석한 자료에 대한 독립 최종 검정은 아니다.
- 결과를 보고 특징·깊이·전환 기준을 재조정하지 않는다. 운영 검색 코드는 변경하지 않는다.
