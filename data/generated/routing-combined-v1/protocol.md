# 45단계 실행 전 설정

- 코퍼스: search-holdout(84,413청크) + search-docs-only(1,198청크), 해석한 실제 인덱스를 고정.
- 질문: 42단계의 docs135·holdout69 결과에서 보정된 질문/정답을 추출해 204문항으로 고정한다. 새 방식의 결과를 보고 gold를 선택적으로 바꾸지 않는다.
- 현재 코드로 세 방식 모두 재검색. as_of=2026-09-25, k=5(깊이도 5), 반복 1회, 재작성 끔. 같은 정답으로 채점한다.
- 44단계 모델/특징/전환 기준을 그대로 적용. 정답 부모 연결 성분으로 5분할하고 OOF 예측 평가. 질문만/질문+결과 두 모델 모두 보고한다.
- 별도 36문항은 기존 validation-v2의 core+docs 반환 보정본을 사용하고 모델 학습과 기준 선택에 쓰지 않는다. 204문항과 정답 부모가 겹치는 경우 따로 표시하고 문서 분리된 성능을 우선 보고한다.
- 이 자료 모두 기존 개발 중 분석했으므로 완전히 새로운 독립 시험이라고 주장하지 않는다.
- 전체 문서 Precision 및 근거 Precision은 정답 라벨 범위에 따른 하한이다. 결과가 기존 정답에 없다는 이유만으로 실제 무관하다고 확정하지 않는다. 정답 없는 질문은 제외한다.
- 운영 검색 코드는 변경하지 않는다. 결과를 보고 전환 임계값을 다시 고르지 않는다.
