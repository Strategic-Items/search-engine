# Dense 입력에서 제목 경로 제거 비교 — 2026-10-06

기존 `title + heading_path + body`에서 별도로 추가하던 `heading_path`를 빼고 `title + body`로 인코딩했다. `title`에 파서가 이미 붙인 조문·절 제목과 본문 속 제목은 제거하지 않았다. 모델, 문서·청크, 질문, SPLADE 벡터·후보, 컷오프, RRF 설정은 고정했다. 운영 인덱스나 별칭은 변경하지 않았다.

dense 벡터를 바꾸면 HNSW 검색 그래프도 바뀌므로, 입력 효과와 근사 검색 차이를 분리했다. 기존 벡터와 경로 제거 벡터를 동일하게 정확한 코사인으로 검색했다. 점수는 현재 Faiss 결과와 확인한 `(1+cosine)/2`를 사용하고, 유효기간·번호 필터는 현재 인덱스에서 그대로 적용했다. 기존 서비스의 근사 검색 결과도 별도 대조군으로 재실행했다.

## 판단

별도 heading_path를 제거하면 dense 단독 근거 회수는 법령 90→89/100, 행정 28→27/30으로 각각 한 문항 내려갔다. hybrid의 근거 회수는 법령 91→91/100, 행정 27→27/30으로 그대로였다. 법령 hybrid는 새로 찾은 질문 1개와 잃은 질문 1개가 상쇄되었고 근거 MRR은 정확 검색 기준 0.798→0.785로 내려갔다. 행정 hybrid는 성공/실패 문항이 그대로이며 근거 MRR은 0.719→0.753으로 올라갔다.

현재 비교에서는 두 카테고리 전체에 경로 제거를 적용할 근거가 부족하다. dense의 기존 경로 포함 기본값을 유지하고 제거 옵션만 추가한다. 새로 얻은 일반화 성능으로 해석하지 않는다.

대조군에서 법령 서비스 ANN과 정확 검색의 회수 성공/실패는 모두 일치했고 반환 목록은 각 모드에서 1문항만 달랐다. 행정은 모든 반환 목록까지 일치했다. 따라서 위 한 문항씩의 회수 손실은 근사 검색 그래프를 재구축한 영향과 분리된 입력 비교 결과다.

## 해석 범위와 검증

- 제거한 것은 검색 색인 과정에서 별도로 덧붙인 heading_path다. 문서 title에 포함된 조문 표기까지 지운 실험이 아니다.
- 입력 변화는 정확 검색끼리 비교한다. 서비스 ANN과 정확 검색의 차이는 별도로 기록했다.
- 점검용 법령 100문항과 행정 30문항의 라벨 근거 회수 결과이며 생성 답변 정확도나 새 자료에서의 일반화 성능을 측정한 것은 아니다.
- 라벨 Precision은 하한이다. 같은 답을 담은 다른 판·라벨 밖 관련 청크를 오답으로 계산할 수 있다.
- 경로 제거 벡터는 본문·제목을 바꾸지 않고 기존 ID 순서로 생성했으며 변경되지 않은 입력의 벡터는 그대로 재사용했다.
- 기존 색인·준비 테스트 31개 통과. dense 입력 옵션의 true/false 두 표현을 확인했다.
- 수정 Python 파일과 비교 스크립트 문법 검사 통과.
