# 단계 1~7 한눈에 보기

단계 1~7을 같은 표에서 비교한다. 단계별 서술은 각 단계 문서에 있다.

| 단계 | 코퍼스 / 평가셋 | BM25: Hit@1 / Recall@5 / Recall@10 / p50 | dense: Hit@1 / Recall@5 / Recall@10 / p50 | 하이브리드: Hit@1 / Recall@5 / Recall@10 / p50 | 해석 |
|---|---|---|---|---|---|
| 1. 초기 기준선 | 초기 파서 스냅샷 `745821…`, v1 키워드 성향 질문 50개 | 90.0% / 98.0% / 100.0% / 16.6ms | 38.0% / 58.0% / 65.0% / 52.9ms | 68.0% / 87.0% / 99.0% / 71.3ms | 제목·코드·키워드가 많은 세트라 BM25가 특히 유리했다. |
| 2. 자연어 기준선 | 같은 스냅샷 `745821…`, v2 자연어 질문 40개 | 72.5% / 85.0% / 87.5% / 15.0ms | 12.5% / 22.1% / 49.6% / 48.3ms | 45.0% / 67.9% / 85.0% / 66.1ms | 표현 변경·상황형 질문을 넣자 dense와 하이브리드의 약점이 드러났다. 1단계와 직접적인 성능 하락 비교는 불가하다. |
| 3. 최신 파서 재추출·재색인 | 최신 파서 산출물 `4c8ef3…`, v2 자연어 질문 40개 | 72.5% / 85.0% / 87.5% / 15.0ms | 12.5% / 22.1% / 49.6% / 46.7ms | 42.5% / 67.9% / 85.0% / 65.9ms | 2단계와 사실상 동일하다. 파서 개선은 메타데이터 중심이었고 기본 청크 본문/경계가 거의 같았다. |
| 4. 문서당 청크 4개 반환 | 3단계와 같은 코퍼스·질문 | 72.5% / 85.0% / 87.5% / 15.8ms | 12.5% / 22.1% / 49.6% / 56.4ms | 42.5% / 67.9% / 85.0% / 75.2ms | 문서 지표는 설계대로 전부 그대로다. 달라진 것은 아래 근거 청크 표뿐이다. |
| 5. 질의 재작성 융합 (기본 꺼짐) | 4단계와 같은 코퍼스·질문 | 77.5% / 87.5% / 90.0% / 605.5ms | 12.5% / 22.1% / 49.6% / 51.6ms | 45.0% / 77.9% / 87.5% / 684.4ms | 문서 지표가 처음으로 올랐다. 대가는 검색당 약 0.6초다. dense 단독은 어휘 경로를 쓰지 않아 해당 없음. |
| 6. 임베딩 모델 `bge-m3` (재작성 꺼짐) | 4단계와 같은 코퍼스·질문, 재색인 | 72.5% / 85.0% / 87.5% / 18.8ms | **87.5% / 100.0% / 100.0% / 73.3ms** | 80.0% / 92.5% / 100.0% / 95.3ms | 순위가 뒤집혔다. dense가 모든 품질 지표에서 1위다. 1~5단계 dense의 약세는 검색 방식이 아니라 모델 선택의 결과였다. |
| 7. `bge-m3` + 질의 재작성 | 6단계와 같은 조건, 재작성만 켬 | 77.5% / 87.5% / 90.0% / 529.3ms | 87.5% / 100.0% / 100.0% / 98.2ms | 80.0% / 92.5% / 100.0% / 687.4ms | dense는 어휘 경로를 쓰지 않아 그대로이고, 하이브리드는 품질이 동일한데 p50만 7배가 된다. 6단계 대비 얻는 것이 없다. |

`Hit@1`은 1위가 정답 문서인 질문 비율이고, `Recall@k`는 질문별 정답 부모 문서
회수율의 평균(macro)이다. p50은 중앙 지연시간이다.
