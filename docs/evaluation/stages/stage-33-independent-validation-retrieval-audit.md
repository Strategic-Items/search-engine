# 33단계: 동결한 새 질문으로 검색 검증과 반환 근거 점검

## 목적과 설정

31단계에서 출처 문서 36개를 표본 추출하고, 32단계에서 각 문서에 대한 질문과 최초 정답표를 **검색 실행 전에** 커밋했다. 이 단계에서는 `title^1`과 다중 인덱스 DFS를 포함한 현재 설정을 그대로 사용했다. 두 질의셋 모두 정답이 존재하는 질문만 포함한다. 무응답 판정은 이 단계의 범위가 아니다.

원본 질문 파일은 `data/queries_validation_v2.jsonl`(core)과 `data/queries_validation_v2_combined.jsonl`(core+docs)이다. 실행 결과는 `data/generated/validation-v2/results/`에 보존했다. API는 로컬 8112(core), 8113(core+docs), 상위 문서 5개 기준이었다. 질의는 검색 설정을 선택하는 데 사용하지 않았다.

## 최초 정답표와 반환 문서 판정

| 조건 | 1위 정답 | 5위 내 정답 | 근거 Recall@5 | 반환 문서 Precision@5 |
|---|---:|---:|---:|---:|
| core, 최초 정답표 | 26/36 | 30/36 | 0.833 | 0.633 |
| core+docs, 최초 정답표 | 27/36 | 30/36 | 0.833 | 0.640 |
| core, 반환 근거 추가 | 33/36 | 34/36 | 0.944 | 0.738 |
| core+docs, 반환 근거 추가 | **34/36** | **34/36** | **0.944** | **0.757** |

상위 결과의 실제 청크를 읽고, 답과 근거를 직접 담은 문서 11개를 7문항의 정답 대안으로 추가했다. 판정 기록은 `data/generated/validation-v2/returned_gold_audit.json`, 파생 질문 파일은 `queries_core_returned_audited.jsonl`과 `queries_combined_returned_audited.jsonl`이다. 원래 동결한 질문 파일은 수정하지 않았다. 대표적인 누락 사례는 다음과 같다.

- 024: 기존 정답 이외에 반환된 세 자료 모두 `9B105`와 마하 0.9 기준을 정확히 적었다. 처음의 5위 내 실패 판정은 정답표 누락이었다.
- 002: 전자매체·구두 이전을 다룬 문서와 이메일·교육·실연을 열거한 FAQ를 추가했다.
- 028: 반환된 FAQ 첨부의 바세나르용 별지 2-3 서식에도 연락 담당자의 전화·이메일란이 있다.
- 030: 반환된 다른 별지 제7호 서식에도 영문 제목 `Korean Import Certificate`가 있다.
- 003, 018, 019도 반환 청크에 질문의 답이 직접 적혀 있어 정답 대안을 추가했다.

보정 후 core+docs의 근거 청크 Precision@5는 **하한 0.438**(평균 반환 5.50청크), 문서 Precision@5는 **하한 0.757**(평균 반환 2.19문서)이다. 추가한 것은 확인된 11문서뿐이다. 나머지 반환 문서를 전수 판정한 수치가 아니므로, 이 precision을 실제 오답 비율로 해석하면 안 된다. 질문과 추가 판정 모두 사람 검수 전이다.

## 남은 실제 실패

동등한 정답 근거를 추가한 뒤에도 007과 036은 상위 5문서에 정답이 없다. 모두 CP 보고 기한을 묻고, **연도와 보고 대상 기간**이 다른 공고·발표 자료가 앞에 나온다.

- 007: 질문은 2026년 상반기 실적보고(2026-07-31, AAA 연 1회)인데, 검색 상위에는 2014·2018년 자료가 포함된다.
- 036: 질문은 2020년 하반기 실적보고 및 운영보고(2021-01-31)인데, 상위에는 2019년 안내와 2024년 하반기 안내가 나온다.

두 정답 문서는 모두 색인돼 있다. 따라서 현재 확인된 실패는 색인 누락이 아니라 **유사한 제목과 본문을 가진 연례 자료 사이에서 질문의 연도·기간을 충분히 구별하지 못한 검색 순위 문제**다. 이 사례만 보고 연도 가중치를 정하면 이 검증셋에 과적합된다. 여러 연도와 다른 주제의 날짜 질문을 별도로 동결하고, 기존 docs·holdout 회귀를 함께 본 뒤 일반 규칙을 검토해야 한다.

## 판단과 다음 일

새 질문에서 `title^1`+DFS의 보정 후 1위 정답은 34/36이다. 현재 설정의 새 검증셋 성능을 기록했으며, 이 질문으로 검색 파라미터를 재선택하지 않는다. 다음은 (1) 007·036의 연도/기간 충돌을 재현할 새 날짜 질문셋을 검색 전에 동결, (2) 후보 개선을 기존 평가셋과 새로 동결한 질문셋 양쪽에서 검사, (3) 이번 36문항과 정답 추가분의 사람 검수다. 무응답 질문에는 별도 판정자가 필요하므로 여기서 다루지 않는다.
