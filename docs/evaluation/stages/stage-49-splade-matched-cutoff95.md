# 49단계: SPLADE를 현재 95% 청크 컷오프 결과와 같은 조건으로 비교한다 (2026-09-28)

기존 프론트 SPLADE 표는 24단계의 상위 5청크 지표였다. 대표 카드의 47단계 95% 컷오프 지표(Recall 94.4%, Precision 42.5%, 청크 1위 정확도 72.6%)와 평가 창 및 컷오프가 달라 직접 비교할 수 없었다. 동일한 전달 정책으로 다시 평가해 프론트 비교표를 교체했다.

## 비교 조건

동일 docs 135문항, 같은 고정 인덱스에서 두 LLM 판정자·리랭커·쿼리 재작성 없이 실행했다. BM25+벡터는 현행 retrieve 경로를 그대로 사용했다. SPLADE+벡터는 같은 경로에서 어휘 후보만 저장된 `telepix/PIXIE-Splade-v1.5` 순위로 교체했다. 저장 SPLADE 청크 ID가 현재 인덱스에 모두 존재함을 확인했고 동일 유효기간·공고번호 필터를 적용했다. 벡터 질의 및 후보 응답은 같은 질의 내에서 공유했다.

두 방식 모두 어휘 융합 비율 0.90, 벡터 융합 비율 0.97, 문서 최종 비율 0.90과 검색기 선두 예외를 사용했다. BM25 원시 하한 14.75는 SPLADE 점수 척도에 적용하지 않았다. 이는 SPLADE 하한을 독립적으로 보정한 실험이 아니다. 두 방식 모두 최대 5개 문서와 문서당 최대 6개 청크를 선택하고, 전체 선택 청크 중 최고 벡터 검색 점수의 95% 이상을 유지했다. 벡터 후보에 없어 점수를 알 수 없는 청크는 기존 47단계와 같이 보존했다.

새 BM25 기준 결과는 프론트 대표 수치의 `chunk-cutoff-95.json` 지표 및 청크 1위 98문항과 정확히 일치함을 확인했다.

| 지표 | BM25+벡터 (95%) | SPLADE+벡터 (95%) | 변화 |
|---|---:|---:|---:|
| 문서 Recall | 91.05% | 89.20% | -1.85%p |
| 문서 Precision | 93.85% | 93.23% | -0.62%p |
| 문서 1위 정확도 | 95.56% | 97.04% | +1.48%p |
| 청크 Recall | 94.44% | 94.07% | -0.37%p |
| 청크 Precision 하한 | 42.45% | 42.39% | -0.06%p |
| 청크 1위 정확도 | 72.59% | 74.81% | +2.22%p |

첫 청크가 정답인 질문은 98/135에서 101/135로 3개 늘었다. 질문당 평균 전달 청크는 4.04개에서 4.00개다. 근거 전부 전달 비율은 두 방식 모두 92.59%다.

SPLADE는 첫 청크 순서에서 개선됐지만 근거 Recall과 라벨 Precision이 소폭 낮아졌다. 기존 24단계에서 측정한 상위 5청크 개선을 현재 전달 창의 개선으로 해석해서는 안 된다. 관련 맥락을 포함하는 Precision은 사용자 요청에 따라 화면에 넣지 않았고 이번 비교에서도 사용하지 않았다.

## 범위와 적용

저장된 SPLADE 모델 출력과 현재 벡터 검색을 결합한 오프라인 실험이다. 새 코퍼스 재학습·실시간 SPLADE 지연·무응답 안전성·생성 답변 품질·독립 새 질문의 성능은 측정하지 않았다. 운영 검색 설정은 바꾸지 않았다. 프론트는 질문 목록과 라우팅 섹션 사이의 SPLADE 비교를 이 실행으로 교체했다.
