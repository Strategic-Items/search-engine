# 48단계: 문서는 제목으로 찾고 청크는 본문만 점수 매긴다 (2026-09-28)

47단계의 컷오프가 정답 청크 Precision 80%에 도달하지 못하자, 반복된 문서 제목이 무관 청크의 점수를 올리는 원인인지 시험했다. 문서 검색에는 기존 제목+본문 하이브리드를 유지하고, 청크 점수만 같은 모델의 본문 전용 임베딩으로 바꿨다. LLM 판정자 두 개, 쿼리 재작성, 크로스엔코더는 모두 끄고 평가했다.

## 제목의 영향을 분리한 비교

135개 질문에서 반환된 문서 순위와 문서별 검색 후보 풀을 고정했다. 문서당 6개로 자르기 전 후보를 대상으로, 기존 제목+본문 임베딩과 새 본문 전용 임베딩의 정확한 코사인 유사도를 각각 계산하고 높은 순서로 최대 6개를 선택했다. 후보를 고정했으므로 본문 검색으로 새로운 문서를 찾는 실험은 아니다.

기존 임베딩은 `제목: {title}\n\n본문: {body}`, 비교 임베딩은 `본문: {body}`다. 별도 제목 필드만 제외했으며 본문에 실제로 적힌 제목·소제목은 삭제하지 않았다. 같은 임베딩 모델로 서로 다른 본문 425개의 벡터를 생성했고 본문은 잘라내지 않았다. 질의 벡터는 양쪽이 공유한다.

컷오프는 선택된 전체 청크 중 최고 **코사인 유사도**에 대한 비율이며, 양쪽에 같은 비율을 적용했다. 47단계의 OpenSearch kNN 점수 비율과 숫자 자체를 동일하게 해석하면 안 된다. 이번 비교는 어휘 전용 후보에도 정확한 코사인 점수를 계산하지만 47단계는 벡터 점수가 없는 청크를 보존했다.

제목을 제외하면 더 잘 걸러질 것이라는 가설은 이번 실험에서 지지되지 않았다. 컷오프 없이 최대 6개를 유지하면 Precision은 거의 동일하고, Recall은 96.30%에서 96.67%로 0.37%p 높아졌다. 모든 근거 전달은 94.81%에서 95.56%로 한 질문 개선이다.

그러나 컷오프를 적용하면 본문 전용 점수가 정답 근거를 훨씬 많이 제거했다. 비율 0.95에서 Recall은 제목+본문 85.19%, 본문만 65.93%다. 최고점 청크만 남길 때 Precision도 제목+본문 73.33%, 본문만 62.22%로 더 낮다. 두 방식 모두 시험한 비율에서 80%에 도달하지 못했다.

문서 제목이 본문을 해석하는 데 도움이 되거나 본문 전용 점수의 분포가 다를 가능성은 있지만, 원인 자체를 입증한 것은 아니다. 제목 제거가 검색 품질을 개선한다는 근거가 없으므로 운영 청크 선택 방식을 변경하지 않았다. 별도 임베딩 생성은 실험 캐시에만 저장했고 원래 인덱스를 재색인하거나 API를 재시작하지 않았다.

## 범위와 재현

지표는 기존 정답 청크 라벨 기준 하한이다. 조건·맥락까지 인정하는 23단계의 관련도 Precision과 다른 기준이다. 같은 평가셋에서 비교했으므로 독립 새 질문이나 실제 답변 품질에 대한 일반화를 주장하지 않는다. 본문 자체에 포함된 제목을 지웠을 때의 효과도 측정하지 않았다.
