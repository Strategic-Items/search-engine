# 43단계: 주제·기간 검색 서버 재시작 확인

42단계 변경을 커밋한 후 로컬 8112(core), 8113(core+docs) 서버를 새 코드로 재시작했다. 두 서버의 `/openapi.json`이 HTTP 200을 반환했고, 임시 비교 서버 8114는 검증 후 종료했다.

- 8113에서 날짜 진단 14문항을 재실행했다. 1위 10/14, 상위 5위 14/14, 근거 Recall@5 1.000이다. 42단계 후보 서버와 **질문별 반환 부모·청크 배열이 모두 같다**.
- 8112에서 새 검증 36문항을 재실행했다. 1위 34/36, 상위 5위 36/36, 근거 Recall@5 1.000이다. 39단계 core 서버와 질문별 반환 부모·청크 배열이 모두 같다. 이번 수정이 core 단독의 이 질문들에 새 변동을 만들지 않았다는 확인이다.

결과는 `data/generated/period-topic-v1/results/date14-restarted.json`과 `core36-restarted.json`에 남겼다. 이는 실행 중인 서비스가 커밋한 코드를 사용한다는 확인이며, 42단계에서 밝힌 작은 질문셋과 사람 검수 전 정답의 한계를 넘는 일반화 주장은 아니다.
