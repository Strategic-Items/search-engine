# 2단계: 자연어 기준선

코퍼스는 1단계와 같은 스냅샷 `745821…`이고 평가셋만 v2 자연어 질문 40개로 바꿨다.
바뀐 것이 질문뿐이므로 **1단계와의 차이는 성능 하락이 아니라 난이도 변화다.**

| 단계 | 코퍼스 / 평가셋 | BM25: Hit@1 / Recall@5 / Recall@10 / p50 | 벡터: Hit@1 / Recall@5 / Recall@10 / p50 | 하이브리드: Hit@1 / Recall@5 / Recall@10 / p50 | 해석 |
|---|---|---|---|---|---|
| 2. 자연어 기준선 | 같은 스냅샷 `745821…`, v2 자연어 질문 40개 | 72.5% / 85.0% / 87.5% / 15.0ms | 12.5% / 22.1% / 49.6% / 48.3ms | 45.0% / 67.9% / 85.0% / 66.1ms | 표현 변경·상황형 질문을 넣자 벡터와 하이브리드의 약점이 드러났다. 1단계와 직접적인 성능 하락 비교는 불가하다. |

표현 변경형·상황형 질문을 넣자 벡터와 하이브리드의 약점이 드러났다. 다만 이 시점의 벡터는
`nomic-embed-text`(768차원)를 쓰고 있었고, 그 약세의 원인은 [6단계](../applied/stage-06-embedding-model.md)에서
검색 방식이 아니라 모델 선택이었음이 밝혀진다.

근거 청크 기준 지표는 [단계 2~7 근거 청크 지표](../../evidence_chunk_metrics_v2.md)에 있다.
