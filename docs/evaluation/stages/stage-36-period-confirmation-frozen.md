# 36단계: 기간 구별 개선 확인용 질문 동결

35단계의 날짜 질문을 본 뒤에는 그 질문에서 수치가 가장 높은 가중치를 선택하지 않는다. 개선 후보를 구현하거나 검색하기 전에, 아직 목표 질문으로 사용하지 않은 CP 보고 기간 8개에서 질문을 작성해 [질문셋](../../../data/queries_date_confirm_v1.jsonl)을 동결했다. SHA-256은 `848e3e800a5c8752ac0cc14e97003d9981d8929738815422651aa9d6b36ef611`이다. [매니페스트](../../../data/generated/date-confirm-v1/manifest.json)에 작성 경위와 해시를 남겼다.

대상은 2014년 상반기, 2016년 상반기, 2018년 상·하반기, 2020년 상반기, 2021년 하반기, 2023년 상·하반기다. 마감일뿐 아니라 등급 대상과 제출 자료도 묻는다. 각 답은 지정 문서의 해당 청크에서 공백 정규화한 근거 문구로 검사했다. 원래 문서 외의 동등 답은 검색 후 별도로 판정한다.

이 문서들이 이전 진단의 **반환 후보로 보인 적은 있으므로**, 전혀 보지 못한 문서의 무작위 추정치라고 주장하지 않는다. 그러나 질문은 후보 구현 전에 동결했고, 개선 후보의 수치를 보고 바꾸지 않는다. 새 질문, 기존 날짜 진단, 기존 docs·holdout 평가를 모두 비교해 회귀가 없는지 판단한다. 질문과 판정은 사람 검수 전이다.
