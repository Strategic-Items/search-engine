# 47단계: LLM을 끄고 점수 컷오프로 청크 Precision 80%를 시험한다 (2026-09-28)

사용자는 청크 관련도 LLM 및 무응답 판정자 없이 컷오프를 높여 청크 Precision 80%에 도달할 수 있는지 물었다. 두 판정자와 쿼리 재작성, 리랭커를 끄고 기존 docs 질문 135개를 현재 인덱스에서 다시 검색했다. 검색 후보와 질의 임베딩을 질의별로 캐시하고 동일한 원시 검색 결과로 45가지 컷오프 조합을 비교했다. 운영 설정은 변경하지 않았다.

문서 비율은 0.90/0.95/0.98/0.99/1.00, 청크는 비율 0(끔)/0.95/0.98/0.99/0.995/1.00 또는 절대 점수 0.80/0.85/0.90을 비교했다. 단일 벡터 검색기로 축소되는 질의의 기존 문서 비율 0.99는 낮추지 않았다. 문서 컷오프의 검색기 선두 면제 규칙도 유지했다.

청크 비율은 반환 후보 전체의 최고 벡터 검색 점수에 대한 비율이다. 모든 문서에서 그 기준을 통과하는 청크만 남기고, 청크가 하나도 안 남으면 문서를 제외한다. BM25 점수와 벡터 점수를 같은 척도로 섞지 않는다. 벡터 후보에 없어 점수를 알 수 없는 청크 21개는 보존했다. 이 필터는 실험 스크립트에서만 실행했으며 프로덕션 검색에는 추가하지 않았다.

## 문서 비율 0.90을 고정한 청크 컷오프

| 청크 비율 | 청크 Precision 하한 | 청크 Recall | 평균 전달 청크 |
|---|---:|---:|---:|
| 끔 | 27.36% | 96.30% | 5.60개 |
| 0.95 | 42.45% | 94.44% | 4.04개 |
| 0.98 | 59.95% | 85.19% | 2.18개 |
| 0.99 | 66.43% | 77.41% | 1.61개 |
| 0.995 | 68.36% | 75.19% | 1.39개 |
| 1.0 | 68.91% | 68.89% | 1.16개 |

문서 컷오프만 0.90에서 1.00으로 올리면 청크 Precision은 27.36%에서 28.01%로 소폭 오른다. 최고 점수 문서를 남겨도 그 문서 안의 청크를 자르는 것은 아니기 때문이다.

확인한 45조합 중 최고 청크 Precision은 68.91%이며 Recall은 68.89%다. 80%를 달성한 조합은 없다. 청크 비율 0.95는 Precision 42.45%, Recall 94.44%로, 손실이 작은 쪽의 후보다. 0.98은 Precision 59.95%, Recall 85.19%다. 따라서 Precision 숫자만 올리려 강하게 자르면 정답 근거 손실이 커진다.

절대 바닥값도 개선을 보장하지 않았다. 0.80에서 전체 질문 평균 Precision 33.06%, Recall 48.15%이며 결과가 남는 질문은 82/135다. 그 82문항만 계산한 조건부 Precision은 54.43%다. 빈 결과 질문을 제외해서 높은 수치를 얻는 것과 전체 질문에서 좋은 검색을 하는 것을 구분해야 한다.

## 범위와 해석

80% 목표는 기존 화면과 같은 정답 청크 라벨 기준 하한으로 해석했다. 유용한 조건·맥락은 정답 라벨이 없으면 비정답으로 계산된다. 이 실험은 동일 평가셋의 후보 튜닝 실험이며 독립 일반화 성능이나 답변 품질을 증명하지 않는다. 제목 때문에 높은 점수를 받는 현상을 직접 분리해 검증한 실험도 아니다.
