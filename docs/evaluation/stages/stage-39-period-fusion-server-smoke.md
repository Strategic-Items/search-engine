# 39단계: 기간 일치 검색 서버 재시작 확인

38단계 코드를 커밋한 뒤 로컬 검색 서버 8112(core)와 8113(core+docs)를 재시작했다. 두 서버 모두 `/openapi.json`에 HTTP 200으로 응답했다. 임시 비교 서버 8114는 검증 뒤 종료했다.

- 8113에서 35단계 날짜 진단 14문항을 다시 실행했다. 1위 10/14, 5위 내 12/14, 근거 Recall@5 0.857로 38단계 후보와 같고, **질문별 반환 부모와 청크 배열도 모두 같았다**. 결과는 `data/generated/date-validation-v1/results/restarted-stage39-audited.json`.
- 8112에서 33단계 새 검증 36문항을 다시 실행했다. 1위 34/36, 5위 내 36/36, 근거 Recall@5 1.000이다. 이전 core 단독 결과는 각각 33/36, 34/36, 0.944였다. 결과는 `data/generated/validation-v2/results/core-period-restarted.json`.
- 원래 실제 실패였던 007의 2026년 상반기 공고는 core 단독 2위로, 036의 2020년 하반기 공고는 1위로 돌아왔다. 두 문서 모두 이전에는 core 상위 5위 밖이었다.

이 검사는 재시작한 실제 서버가 커밋된 기간 일치 코드를 실행하는지 확인한다. 응답 품질의 일반화 범위는 38단계의 질문 구성과 사람 검수 전 판정 한계를 따른다. 정답 없는 문서 판정은 포함하지 않았다.
