# 44단계: 판본을 지정하지 않은 질문에서 대체된 문서의 청크 점수를 깎아 봄 (2026-10-07)

법령·고시 100문서·4,633청크·100문항(`search-law`)의 hybrid(SPLADE C + dense, 청크 RRF k=60, 컷오프 0.95)에서, 질문이 판본을 지정하지 않으면 `superseded_by`가 있는 문서의 청크 RRF 점수에 가중치를 곱해 컷오프 전에 순서를 바꿨다. 가중치를 1.0~0.0으로 훑어 곡선을 얻었다.

**상태: 선택 기능으로 코드에 넣고 기본은 끈다.** `SEARCH_CHUNK_FIRST_SUPERSEDED_WEIGHT=1.0`(기본, 동작 변화 없음). 운영 인덱스·별칭·컷오프·모델은 바꾸지 않았다. 기본 꺼짐인 선택 기능도 applied에 기록하는 저장소 규칙에 따라 이 폴더에 둔다.

## 판단

- **효과는 작다.** 가중치 0.97에서 청크 Recall 91→92/100(질문 048 하나), MRR 0.793→0.807, 청크 Precision(하한) 0.558→0.561, 반환 문서 중 대체된 문서는 질문당 1.04→0.89개다. 질문을 잃지 않는다.
- **가중치를 더 낮추면 손해가 난다.** 0.90 이하는 Recall이 91로 돌아가고(073을 잃음), Precision이 0.537~0.538로 내려간다. 0까지 내려도 대체된 문서가 질문당 0.64개 남는다. 질문 1위 청크는 컷오프 예외라 깎이지 않기 때문이다.
- **기본은 끈다.** 얻은 것이 한 문항이고, 가중치를 고른 질문 셋이 평가 셋과 같다. 법령 100문항에서 정답 문서 중 대체된 문서가 있는 질문이 42개라서(전부 대체된 질문은 4개), 판본 우대는 라벨과 어긋날 위험이 크다.
- **행정·업무는 동작하지 않는다.** `search-admin`에 `superseded_by`가 있는 문서가 0개라 어떤 가중치에서도 결과가 같다(27/30·MRR 0.719). 행정의 옛 판 문제(멘토링 2018, 공적요지 2014 등)는 이 규칙으로 풀 수 없고, 파서 출력에 날짜·대체 관계가 없다는 것이 먼저 풀려야 한다.

## 놓친 질문과 판본의 관계

기준 hybrid가 놓친 9문항(043·048·058·067·075·076·077·080·084) 중 판본 순위로 설명되는 것은 048 하나다. 나머지는 정답이 다른 별표·서식에 있거나, 정답 문서가 여러 개라 한 판만 반환해 라벨과 어긋나거나(067·077), 같은 문서의 다른 청크가 앞서는 경우다. 판본 순위 규칙의 상한이 낮은 이유다.

옵션을 켜도 인덱스를 다시 만들 필요는 없다. 기존 `superseded_by` 필드를 그대로 읽는다.

```bash

.venv/bin/python scripts/law/sweep_superseded_weight.py --alias search-admin --queries data/queries_admin_v1.jsonl
```

테스트 267개가 모두 통과했고, 새 테스트 2개는 기존 파일에 추가했다.

## 해석 범위와 다음 비교

- 질문은 본문을 보고 만든 점검용 100문항·행정 30문항이다. 새 자료에서의 일반화 성능이나 생성 답변 정확도는 측정하지 않았다.
- 대체 관계(`superseded_by`)는 파서가 같은 제목으로 추론한 값이 대부분이고, 잘못 붙은 사례가 있을 수 있다. 이 규칙은 그 값을 맞다고 보고 쓴다.
- 판본 지정 표현은 정규식이라 놓치거나 잘못 잡는 질문이 있을 수 있다. 법령 100문항에서 22개를 잡았고, 직접 읽어 확인하지는 않았다.
- 시험하지 않은 것:
  - **대체 관계를 문서 ID로 푸는 것.** `superseded_by` 대부분(9/11문서)이 parent_id가 아닌 고시·대통령령 번호를 가리켜 `_with_current_editions`가 새 판을 붙이지 못한다. 번호가 여러 문서(본문·대비표·개정문)에 걸려 모호해서 별도 설계가 필요하다.
  - **새 판 추가가 정답을 밀어내는 문제.** 42단계에서 확인한 대체 연결 문서 삽입 뒤의 5문서 상한 문제는 그대로다.
  - **행정·업무 판본.** 파서 출력에 `superseded_by`·날짜가 없어 규칙이 걸리지 않는다.
