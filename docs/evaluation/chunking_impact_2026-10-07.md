# 청킹 변경의 dense·SPLADE 영향도와 근거 반환 비교

## 측정 범위
98개 질문에 연결된 143건을 측정했다. 현재 모델과 배경 코퍼스를 고정하고 대상 문서의 Git 전후 청크를 교체했다. 질문 전체 비교는 해당 커밋으로 모델 입력이 달라진 현재 문서를 함께 교체했다.

- dense: 비교 청크의 정확한 코사인, 질문 어절 삭제 전후 영향, 수정 구간 삭제 영향.
- SPLADE: 질문·청크 희소 벡터 내적, 토큰별 기여, 수정 구간 삭제 영향.
- 후보와 반환: SPLADE/dense 각각 25개 후보의 RRF(k=60), 80%/93%/95% 컷오프, 10청크/5문서/문서당 6청크. Hybrid는 저장소의 실제 문서 묶음·사본 제외 함수로 계산했다.
- 질문 근거: 허용된 정답 문서의 필수 답 구절을 반환 청크에서 충족하는지 확인했다. 111·125·143은 단위까지 필요하다. 운영 LLM 답변 품질을 측정한 것은 아니다.

## 해석 범위

점수 상승은 순위 상승의 충분조건이 아니다. 경쟁 청크와 후보 수·컷오프가 영향을 준다. 단위나 예외를 추가하면 dense 점수가 내려가도 답변 근거는 완전해질 수 있다. 제목 경로를 모델 입력에 넣지 않는 설정에서는 경로만 바뀌어도 모델 점수는 바뀌지 않는다.

코사인·희소 내적으로 오프라인에서 정확히 다시 정렬한 실험이다. 실험마다 수정 전후 문서 구성과 모델 입력 외 배경은 고정했다. 운영 ANN 색인 재생성·날짜/번호 필터·판본 가중치·LLM 답변 평가를 포함하지 않았다. 필수 구절 판정은 현재 ID 기반 라벨을 과거 청크 번호에 옮기는 방식이 아니며, 복수 반환 청크에 걸친 근거도 함께 확인한다.
