# 정답 적중의 근거 재검증 (2026-10-07)

질문 탐색기의 법령 100·행정 30·민원 FAQ 30문항에 대해 기존 정답 라벨과 앞서 추가한 33청크를 반대 방향으로 점검했다. 전체 라벨의 본문/원본 ID/heading_path를 읽어 국가·조문·통제번호·지정 판·개정 전후·목차·질문과 답의 행위 방향을 검사하고, 발견한 오류 유형에는 검토한 제약을 적용했다. 결과의 `scope_checks_passed`는 이 검사를 통과했다는 뜻이며, 임의의 모든 법적 해석이나 조건의 완전성을 LLM으로 인증했다는 뜻은 아니다. 이 작업은 저장된 문서 근거와 평가 라벨을 다루며 현행 법률 판단을 하지 않는다.

## 결과

- 160문항, 수정 전 라벨 477개와 새 맥락 연결 청크 1개를 포함한 478개 라벨 기록을 남겼다.
- 24문항에서 근거 요건을 충족하지 못하거나 입증이 부족한 라벨 109개를 제외했다. 삭제 이유와 본문을 JSON 보고서에 보존했다.
- 앞서 추가한 33청크 중 6개를 철회했다. 긴급 수리 면제의 개정 전 청크 2개, 개정예고와 출처가 다른 2020~2024 세부지침 4개이다. 후자의 4개는 내용이 같은 보조 근거로 화면에 표시한다.
- 기존 최종 반환 적중 중 법령 015·039·053, FAQ 025의 4문항이 완전한 정답 적중에서 빠졌다. 점검 전 147개, 점검 후 143개가 반환 근거 요건을 충족한다.
- 법령 053과 FAQ 025는 질문 또는 원본 근거 오류 때문에 지표에서 제외했다. 현재 요약의 평가 대상은 158문항이고, 완전한 반환 근거 충족은 143/158이다. 기존 147/160과 분모가 달라 직접적인 성능 비교로 쓰지 않는다.

## 반영 및 검증

원본 질문 JSONL, 탐색기의 정답 표시·원본 문서 표시·검색별 순위·컷오프 표시·최종 반환·결과 요약에 반영했다. `evidence_groups`는 그룹 사이에 AND, 그룹 안에 OR로 해석한다. 일부 그룹의 청크만 반환되면 ‘일부 근거 반환 · 요건 미충족’, 잘못된 질문은 ‘평가 제외 · 근거 확인 필요’로 표시한다.

재생성 시 `evaluate_law.py build`가 동일 검증을 적용한다. 법령 평가 스크립트는 제외 문항을 분모에서 빼고 모든 그룹의 반환 여부를 검사한다. 검색 점수·후보 순서·컷오프·반환 청크와 임베딩 기여도는 다시 계산하거나 바꾸지 않았다. 과거 실험 수치는 당시 라벨로 측정한 값이므로 소급 수정하지 않았다.

재현:

```sh
.venv/bin/python scripts/law/reconcile_explorer_labels.py
.venv/bin/python scripts/law/audit_explorer_positives.py
.venv/bin/python -m pytest tests/evaluation/test_category_equivalent_labels.py -q
```

조건·통제번호·지정 판·개정 전후·행위 방향·복수 근거 요건의 회귀 테스트 10개 통과. 160문항의 실제 렌더 함수와 6개 탭을 실행해 표시를 검사했고, 수정 전후 검색 점수·후보 순서·컷오프·반환 청크가 같음을 비교했다. Python 컴파일 및 JavaScript 문법 검사 통과.

검토 제약은 `data/label_reviews/category_positive_constraints_2026-10-07.json`, 문항·청크별 검사 결과와 제외 이유/본문은 이 문서와 같은 이름의 JSON에 있다. 저장된 FAQ 화면 질문과 FAQ v2의 표현이 일부 달라 JSON에 두 질문을 함께 기록했다.
