# 서식 대체 관계 — 2026-09-15

색인 전체에서 `effective_to`가 채워진 문서는 **0건**이었다. 즉 폐지·대체된 문서를
걸러낼 데이터가 없었고, 유일한 대응은 `prepare.py`에 문서 ID를 손으로 적는
`EXCLUDED_CORE_IDS` 한 줄이었다. 자료가 계속 들어오면 유지될 수 없는 방식이다.

## 신호는 제목에 있었다

서식 제목이 자기 자리를 스스로 밝힌다. 표기가 두 가지로 섞여 있어 그동안 이어지지
않았을 뿐이다.

```
[38차 개정, 26.9.1] 별지 4. 전문판정(신청)서     ← 2026-09-04
[별지 제4호 서식] 전문판정(신청)서                ← 2021-12-02
```

같은 `별지/별표` 번호를 정규화해 묶고 게시일 순으로 세우면, 옛 판을 새 판이 대체한
관계가 나온다. 부모 문서 43건 중 **6건**이 대체된 것으로 잡혔다.

| 대체된 문서 | 대체한 문서 |
|---|---|
| 2018-04-16 별지 제6호 포괄수출허가(신청)서 | 2026-09-04 38차 별지 6 |
| 2018-04-16 별지 제7호 전략물자 수입목적확인(신청)서 | 2026-09-04 38차 별지 7 |
| 2021-12-02 별지 제4호 전문판정(신청)서 | 2026-09-04 38차 별지 4 |
| 2021-12-02 별지 제16호 전략물자 수출거래 보고서 | 2026-05-15 별지 16 사전거래보고서 |
| 2024-02-23 별지 제2호 최종수하인 및 구매인 진술서 | 2026-09-04 38차 별지2 |
| 2024-02-23 별지 제2호의3 최종사용자 서약서 | 2026-09-04 38차 별지 2의3 |

`[행정절차법 별지 제2호] 지위승계 통지서`는 제외했다. 다른 법령의 서식은 번호
체계가 달라 같은 자리로 볼 수 없다. 같은 날 함께 공개된 판(38차 별지 2의3의 두
변형)도 서로 대체하지 않는다.

## 지우지 않고 강등한다

평가셋에 **옛 판을 일부러 찾는 질의가 2건** 있다.

- `2021년 12월에 게시된 전문판정 신청서`
- `2018년 게시 포괄수출허가 신청서 원본 링크`

게시된 기록은 공개돼 있고 이용자는 특정 시점의 판을 근거로 찾는다. 그래서
`effective_to`로 잘라내지 않는다. 대신 `superseded_by`에 대체 문서를 적고, 검색은
대체되지 **않은** 문서에 가점 4를 준다. 두 질의는 질의에 담긴 연도가 기존 연·월
가점을 발동시켜 여전히 1위를 유지한다.

## 옛 판을 찾으면 현행판이 따라온다

38차 개정은 일부 서식의 제목을 영문으로 바꿨다. `별지 2의3`은 한국어
`최종사용자 서약서`에서 `END-USER STATEMENT`가 됐다. 그래서 한국어로 물으면 현행판에
어휘로 닿지 못하고 폐지된 한국어 제목만 맞는다.

검색 결과에 `superseded_by`가 달린 문서가 있으면, 그것이 가리키는 현행판을
**바로 뒤에** 끼워 넣는다. 뒤에 두는 순서가 중요하다 — 앞에 두면 옛 판을 일부러 찾는
질의가 깨진다. 응답의 `superseded_by` 필드로 이용자 화면에서 "이 서식은 대체됨"을
표시할 수 있다.

## 남은 것

`EXCLUDED_CORE_IDS`의 `faq-042`는 이 규칙으로 대체되지 않는다. FAQ는 날짜가 전혀 없고
(206건 모두 `published_at` 없음, 187건이 본문에 `★0226 (9차)` 판 표시), 충돌 상대가
같은 자리의 새 판이 아니라 **다른 출처의 안내 문서**이기 때문이다. 출처 간 내용 충돌은
자동으로 판정할 수 없으므로, 이 한 건은 여전히 사람이 지정한다.
