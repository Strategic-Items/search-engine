## 현재 웹과 같은 반환 깊이 5

BM25 후보 25개 / 벡터 후보 50개. 검색 함수를 직접 실행한 결과이며 브라우저 왕복시간 측정은 아니다.

| 방식 | Hit@1 | Hit@5 | 문서 Recall@5 | 논리 문서 Recall@5 | 근거 Recall@5 | MRR@5 | p50 / p95 ms |
|---|---:|---:|---:|---:|---:|---:|---:|
| BM25 | 72.5% | 85.0% | 85.0% | 85.0% | 30.0% | 0.7663 | 9.4 / 15.2 |
| 벡터 | 12.5% | 25.0% | 22.1% | 23.8% | 10.0% | 0.1571 | 47.8 / 89.7 |
| 하이브리드 | 45.0% | 77.5% | 75.4% | 76.3% | 27.5% | 0.5621 | 58.8 / 84.1 |

Hit은 정답 문서를 하나라도 찾은 질문 비율, 문서 Recall은 질문별 정답 문서 회수율의 평균이다. 논리 문서 Recall은 같은 자료의 다른 파일 형식을 대체 정답으로 묶는다. 근거 Recall은 실제 반환 청크가 라벨링된 근거 요구사항을 얼마나 충족하는지 측정하며 생성 답변의 정확도는 아니다. 라벨에 없는 대체 근거는 인정하지 않으므로 추가 검토가 필요하다.
